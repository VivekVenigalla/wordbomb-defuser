# Word Bomb Defuser

A small Firefox extension that watches a wordbomb.io game and suggests words that fit the
current prompt (the 2-3 letters you must put inside a word).

It only shows suggestions. It never types or sends anything for you.

## Run the tests

    npm test

(Needs Node.js. There is nothing to install: this project has no dependencies.)
